## What's new

This is the first public release of Tanship — a full-stack boilerplate built on Cloudflare Workers and TanStack.

### Core boilerplate

- **TanStack Start** + **TanStack Router** for full-stack React with SSR
- **Hono** API with typed RPC contract (`hc<AppType>`)
- **Better Auth** with email OTP, Google OAuth, sessions, and API keys
- **Drizzle ORM** on Cloudflare D1 — migrations, relational queries
- **Gate RBAC** — role-based access control with policy engine
- **Cloudflare R2** file storage with signed uploads

### Billing & licensing

- **Dodo Payments** one-time purchase flow
- License key email delivery on purchase
- GitHub repository invitation on activation

### Templates marketplace

- 6 premium templates available for individual purchase ($99 each)
- All templates included in the Pro plan ($299)
- Secure per-template R2 download

### Developer experience

- Turborepo monorepo with shared packages
- Biome linting + formatting
- Full TypeScript end-to-end
